Installation
01
Download
Grab the latest .zip from the Releases tab above.
02
Open Magisk or KernelSU
Navigate to Modules → Install from storage.
03
Select the ZIP
Pick the downloaded file and wait for the flash to complete.
04
Reboot
Your new bootanimation will play on the next startup.
Note: If the animation doesn't change after reboot, clear the theme cache manually: Settings → Additional Settings → Theme → Clear cache → Reboot again.
What It Does
Action Path
